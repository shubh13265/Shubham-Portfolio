# Interactive 3D Portfolio

Welcome to my personal portfolio repository! This project is a highly engaging, interactive web portfolio designed to showcase my skills, projects, and achievements as an AI & Full-Stack Developer.

## 🌟 Key Features

- **Interactive 3D Avatar**: A dynamic 3D avatar that elegantly flies into the screen when the page loads, greeting visitors.
- **Neural Network Background**: A fully interactive, responsive particle-based background built with Vanilla JavaScript to represent my passion for AI and Machine Learning.
- **Glassmorphism UI**: A sleek, modern dark-mode aesthetic utilizing CSS glassmorphism, blur filters, and vibrant cyan accents.
- **Interactive Digital Resume**: A beautiful, built-in popup modal containing a complete structured digital HTML resume directly within the web app—no PDF download required!
- **Responsive Design**: Carefully crafted media queries ensure the layout automatically adapts perfectly across desktop monitors, laptops, tablets, and mobile smartphones.
- **Dynamic Content Loading**: The floating navigation dynamically loads different sections (About Me, Projects, Hackathons, Certifications, Experience) directly into the main view with smooth CSS animations.

## 🛠️ Technology Stack

- **HTML5**: Semantic structure for all pages and content.
- **CSS3**: Advanced styling, animations, flexbox layouts, CSS Grid, media queries, and custom keyframes.
- **Vanilla JavaScript (ES6+)**: Handles navigation logic, neural network canvas rendering, resume modal toggling, and 3D avatar animations.
- **Font Awesome**: Integrated icons for social links and certifications.

## 🚀 How to Run

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/shubh13265/Shubham-Portfolio.git
   ```
2. Navigate into the directory.
3. Simply double-click the `index.html` file to open it in your browser, or use an extension like **Live Server** in VS Code for a better development experience.
